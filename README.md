# manufacturing-agents

Manufacturing Resilience & Operator Assist Copilot

An Agentic AI copilot for Industry 5.0 that helps plant teams catch production and quality issues early, find the likely root cause, surface the right SOPs and past fixes, and recommend a next-best action — keeping a human in the loop on every decision.

It pulls together fragmented plant data (MES, ERP, QMS, CMMS, SCADA/PLC, SOPs) and uses a set of specialized agents (Production, Quality, Maintenance, SOP/Knowledge, Sustainability, Supervisor) to turn it into guided, explainable, human-approved recommendations. No critical action runs without approval.
